# TextMeshPro sample

Typewriter reveal, a counting score and a punch-scale kick on TextMeshPro text.

Requires TextMeshPro (built into uGUI 2.0 on Unity 6, or the `com.unity.textmeshpro` package on 2021/2022). Create an empty scene, add `TextDemo` to an empty GameObject, and press Play. On first use Unity may prompt you to import the TMP Essential Resources.

The sample has its own assembly definition that compiles only when TextMeshPro is present, so importing it into a project without TextMeshPro is harmless: it is simply skipped.
