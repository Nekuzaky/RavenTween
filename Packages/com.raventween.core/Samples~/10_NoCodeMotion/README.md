# No-code motion sample

A menu whose buttons cascade in (**Raven Stagger**), grow under the pointer and sink when pressed (**Raven Button Feel**). *Play* hits like a game event (**Raven Feedback**: camera shake, punch, flash and a hit stop), *Options* wobbles (**Raven Motion** with *Jello* on click), and *About* toggles a dialog that slides in and out (**Raven Show Hide**). A coin floats and spins forever with two Raven Motions, and a platform travels back and forth along a path (**Raven Path**).

Create an empty scene, add `NoCodeMotionDemo` to an empty GameObject, and press Play.

The script only builds the scene: every animation comes from components a designer adds in the Inspector. To do the same in your own scene, select an object and open **Tools ▸ RavenTween ▸ Motion Library**.
