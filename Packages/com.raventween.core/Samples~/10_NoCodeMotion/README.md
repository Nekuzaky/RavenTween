# No-code motion sample

A menu whose buttons cascade in (**Raven Stagger**), grow under the pointer and sink when pressed (**Raven Button Feel**), and celebrate when clicked (**Raven Motion** with *Tada* and *Jello* on click). *About* opens a dialog that slides in when it is shown and slides out, then hides itself, when *Close* is pressed. A coin floats and spins forever with two Raven Motions.

Create an empty scene, add `NoCodeMotionDemo` to an empty GameObject, and press Play.

The script only builds the scene: every animation comes from components a designer adds in the Inspector. To do the same in your own scene, select an object and open **Tools ▸ RavenTween ▸ Motion Library**.
